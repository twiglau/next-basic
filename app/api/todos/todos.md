# 常见问题：API 路由中的数据持久化

## 问题

在 `api/todos` 路由中，为什么通过 POST 添加数据后，即使关闭页面重新打开，新加的数据也不会丢失？

## 解释

这是由于 Next.js 路由处理程序的运行机制以及 Node.js 的模块缓存特性决定的：

### 1. 变量定义在服务器内存中

在 `app/api/todos/route.ts` 中，`data` 数组是定义在模块顶层的全局变量：

```typescript
const data: string[] = ["打球", "工作", "练习"];
```

当你调用 `POST` 方法时，代码执行了 `data.push(todo)`，这直接修改了服务器进程内存中的这个数组。

### 2. 服务器进程持续运行

当你运行 `npm run dev` 时，Node.js 进程在后台持续运行。

- **关闭网页**：仅仅是断开了浏览器与服务器的连接。
- **重新打开网页**：浏览器发起新的 `GET` 请求，服务器从内存中读取已经修改过的 `data` 数组并返回。

### 3. 模块缓存 (Module Caching)

Node.js 会缓存加载过的模块。除非你重启服务器，否则 `route.ts` 模块只会被初始化一次，`data` 变量在整个进程生命周期内都是同一个引用。

---

## 什么时候数据会丢失？

在以下情况下，内存中的数据会重置为初始值：

1. **重启开发服务器**：停止并重新运行 `npm run dev`。
2. **触发热更新**：修改并保存了 `route.ts` 文件（Next.js 可能会重新加载该模块）。
3. **生产环境 Cold Start**：如果部署在 Serverless 环境（如 Vercel），当函数实例被回收后，再次启动时数据会重置。

> [!TIP]
> 如果需要跨重启持久化数据，建议使用数据库（如 MongoDB）或读写本地 JSON 文件。
